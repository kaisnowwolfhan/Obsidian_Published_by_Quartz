# 實際使用流程
之後讀一本新書時，可以固定按照這個流程：
```
① 建立 Book Note
        ↓
② 找出核心問題
        ↓
③ 找出 1～3 個核心主張
        ↓
④ 建立作者的論證骨架
        ↓
⑤ 標記重要 Concepts
        ↓
⑥ 找出候選 Mental Models
        ↓
⑦ 判斷哪些真的能跨情境使用
        ↓
⑧ 建立獨立 Mental Model Notes
        ↓
⑨ 將 Models 與來源 Book 連結
        ↓
⑩ 補上機制、辨識訊號、應用、限制
        ↓
⑪ 實際使用後更新模型
```

最後會形成一個很重要的循環：
```
閱讀
 ↓
萃取
 ↓
建立模型
 ↓
使用模型
 ↓
發現問題
 ↓
修正模型
 ↓
再次閱讀
 ↓
建立更好的模型
```

# 三種資訊的界線
## Fact

> 「研究發現某現象。」

回答：「**發生了什麼？**」

## Concept

> 「沉沒成本是一種已經發生且無法回收的成本。」

回答：「**這是什麼？**」

## Mental Model

> 「做決策時，應排除不可回收的過去成本，重新比較未來的成本與收益。」

回答：「**我應該如何思考？**」

## Principle

> 「不要讓過去的錯誤迫使你繼續犯錯。」

回答：「**我應該遵循什麼原則？**」

# 模型萃取標準
不是書中所有重要概念都可以成為 Mental Model。
一個東西至少應該能回答：**「我下次遇到不同問題時，能不能拿它來幫助判斷？」**

可以進一步使用這個五層判斷：
```
書中出現的資訊
       ↓
這是 Fact 嗎？
       │
       ├─ 是 → 保留作證據
       │
       ↓ 否
這是 Concept 嗎？
       │
       ├─ 是 → 視重要性建立 Concept
       │
       ↓
它能解釋某種現象嗎？
       │
       ├─ 是
       ↓
它能跨情境使用嗎？
       │
       ├─ 是
       ↓
它能幫助我進行判斷嗎？
       │
       └─ 是 → 🧠 Mental Model
```

因此：**重要 ≠ 思維模型。**

# Properties
## Book-Status
- to-read
- reading
- finished
- abandoned

## MM-Status
- seed
- developing
- active
- deprecated

| Status       | 意義             |
| ------------ | -------------- |
| `seed`       | 剛從書中發現，尚未充分理解  |
| `developing` | 已整理，但仍在驗證      |
| `active`     | 已確認具有實際分析價值    |
| `deprecated` | 發現模型有重大問題或不再使用 |

## Source-Type(from MM)
- Author
- Synthesized(混合的)
- Self-derived

# 目前的知識系統
```
               📚 BOOK
                  │
        作者的完整思想系統
                  │
   ┌──────────────┼──────────────┐
   ↓              ↓              ↓
Problem        Concepts       Evidence
   │              │
   └──────────────┼──────────────┘
                  ↓
           🧠 MENTAL MODELS
                  │
   ┌──────────────┼──────────────┐
   ↓              ↓              ↓
Mechanism      Application     Limitation
   │              │              │
   └──────────────┼──────────────┘
                  ↓
           Model Network
                  │
         Related / Similar
                  │
                  ↓
           Model Combinations
                  │
                  ↓
             Frameworks
```

其中 **Frameworks** 目前不建立獨立模板，先讓它自然從多個 Mental Models 的關係中形成；等累積足夠模型後，再視需要建立。

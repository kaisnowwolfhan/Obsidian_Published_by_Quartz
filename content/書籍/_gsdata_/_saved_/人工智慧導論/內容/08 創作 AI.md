# 8-1 基礎生成對抗的概念

## 何為對抗式學習
經由不斷對抗而讓雙方持續進步的過程，稱為 **對抗式學習(adversarial learning)**，經由這個過程而學會創造出有自己風格的作品，也是現在的人工智慧領域中最火紅的 **生成模型(generative model)** 的中心思想。

之前幾個章節介紹的是有關監督式學習使用於訓練 **判別模型(discriminative model)** 的例子。判別模型的概念是，給予模型大量的訓練資料進行機器學習(，每筆訓練資料皆為 *輸入資料(input)* 及其對應的 *標籤(label)* )，使之學到資料間的對應關係，並於輸入時能預測正確。
但==生成模型的目標是「創作」，能夠產出訓練資料中沒有出現過的資料==，並不希望模型照著訓練資料完全模仿。

## 數據空間與數據分佈
**數據空間(data space)** 就是裝載著數據的一個抽象空間，也就是所有可能 **數據點(data point)** 的集合。
在提到「空間」這個詞的時候，通常是指現實生活中的物理三維空間，也就是所有可能的「位置」所構成的整體。在數學中，「空間」可以被推導到更一般的概念，也就是所有「同質的元素」所構成的集合。

> [!quote] 說明
> 假設擲一顆骰子數次之後能夠得到一些數值，這些數據式整數，而且範圍在 1 到 6，便可以說這群數據的集合──也就是數據空間──是 {0, 1, 2, 3, 4, 5, 6}

每個數據點在數據空間中出現的趨勢/分佈，就稱為 **數據分佈(data distribution)** 。
![數據空間與數據分佈─08_創作_AI|圖 8-2 以骰子說明 data distribution|500](https://raw.githubusercontent.com/kaisnowwolfhan/Obsidian-Images/refs/heads/master/數據空間與數據分佈─08_創作_AI.jpg)
<center><font color="#7f7f7f">圖 8-2 | 以骰子說明 data distribution</font></center>

> [!quote] 說明
> 以圖像為例。假設有一張彩色照片，長、寬皆為 64 像素(pixel)，而每張彩色照片有 3 個 **通道(channel)**，分別是 R(紅色)、G(綠色)、B(藍色)。
> 以各個通道分別來看，都是一張長寬皆為 64 pixels 的單色照片，每個像素點都代表該點的單色強弱。就每張單色照片來看，其像素點的數值會落在 0 到 255 之間，因此每個像素點的數值總共有 256 種可能性
> 在長、寬皆為 64 pixels 的彩色照片所形成的數據空間中，其數據點有 3×64×64×256 = 3145728 這麼多個了。

# 8-2 生成對抗網路
將故事中的兩位主角替換成類神經網路，如此一來，整個架構就是所謂的 **生成對抗網路(generative adversarial network, GAN)** 。
負責作圖的小明在生成對抗網路中稱為 **生成器(generator)** ，負責判別真偽的小華稱為 **判別器(discriminator)** 。

一般而言，由於真實的圖片數據集非常複雜，若想要生成非常多樣化的圖片，可以在一個數值連續的 **潛在空間(latent space)** 裡，從一個給定的數據分佈中隨機抽取數據點，並且透過生成器，經過複雜的運算，將潛在空間的數據點轉換為圖片空間的數據點。
以下我們用符號 $\underline{G}$ 代表 *generator 的 mathmatical function*，$\underline{D}$ 代表 *discriminator 的 mathmatical function*，從 *latent space 中抽取出的 data point* 以符號 $\underline{z}$ 表示，*真實的 data point* 以符號 $\underline{x}$ 表示。因此，經由 *generator 產生的假數據* 便能以 $\underline{G(z)}$ 表示。

> discriminator 的訓練目標: $D(x)\nearrow \space|\space D(G(z)) \searrow$ 

![8-2_生成對抗網路─08_創作_AI|圖 8-3 基礎生成對抗網路運作模式|500](https://raw.githubusercontent.com/kaisnowwolfhan/Obsidian-Images/refs/heads/master/8-2_生成對抗網路─08_創作_AI.jpg)
<center><font color="#7f7f7f">圖 8-3 | 基礎生成對抗網路運作模式</font></center>

整個訓練對抗生成網路的流程可以分為兩大步驟：
1. 固定生成網路，訓練判別網路
2. 固定判別網路，訓練生成網路

將生成的圖片標記為「假(0 分)」、將真實圖片 data set 的圖片標記為「真(1 分)」。
接下來，每次從真、假 data set 分別抽取一些 data 交給 discriminator 來預測分數，進行類 NN 的 training。

==discriminator 和 generator 都是由類 NN 所組成==，實際的 training 會包含 backpropagation、gradient descent、gradient ascent 等 algorithms 來優化目標 function。

> [!quote] 說明
> 假設 latent space 非常簡單，是一個 1-D 連續空間，空間裡的數值是 0~2，數值的分佈是 **均勻分佈(uniform distribution)**。
> 同時，假設 generator 是非常簡單的 linear function。
> $$ G(z) = az + b $$
> 由於不知道真實 data distribution，當然也不知道 a 和 b 的設值以接近真實 data distribution。在實作上，通常這些 parameters initialization 是 random。
> 
> 假設 a=1 且 b=0，即 $G(z) = z$ ，而真實 data 同樣遵從 uniform distribution，其 data distribution 為 3~7。
> ![8-2_生成對抗網路─08_創作_AI_3|圖 8-7 | 學習階段初期，generated data 與 true data 的 data distribution|500](https://raw.githubusercontent.com/kaisnowwolfhan/Obsidian-Images/refs/heads/master/8-2_生成對抗網路─08_創作_AI_3.jpg)
> 
> <center><font color="#7f7f7f">圖 8-7 | 學習階段初期，generated data 與 true data 的 data distribution</font></center>

無論是真實 data or 生成 data，所有值出現的機率總和為 1。
建立生成模型的目標，是希望經由 ML 的技術讓電腦產生跟 true data 非常接近的 distribution。在上面的例子，我們==期望讓綠色與藍色的區塊重疊。==

紅色線條即為 discriminator 的判別分數，可以看到在綠色區塊(即 generated data)所得到的分數皆貼近 0 分，而在藍色區塊(即 true data)皆得到接近滿分 1 分。

> [!quote] 說明
> 假設經過 training 一段時間，a → 2.5、b 仍為 0，generator 的 function → $G(z) = 2.5z$

接下來透過目標 function 來訓練 discriminator。
![8-2_生成對抗網路─08_創作_AI_4|圖 8-9 判別器、生成器的 parameters 第一次更新後的判別情況|500](https://raw.githubusercontent.com/kaisnowwolfhan/Obsidian-Images/refs/heads/master/8-2_生成對抗網路─08_創作_AI_4.jpg)
<center><font color="#7f7f7f">圖 8-9 | 判別器、生成器的 parameters 第一次更新後的判別情況</font></center>

一開始在 discriminator 還未優化時，對 data 範圍 3~5 的判別分數偏高(如灰色虛線)，經優化後，能給出較合理的分數(如紅色實線)。

> [!quote] 說明
> 接下來，再次進行 generator 的優化: a → 2、b → 3，即 $G(z) = 2x + 3$ 。而 discriminator 也要進行優化。
> ![8-2_生成對抗網路─08_創作_AI_5|圖 8-10(b) | 判別器、生成器的 parameters 第二次更新後的判別情況|500](https://raw.githubusercontent.com/kaisnowwolfhan/Obsidian-Images/refs/heads/master/8-2_生成對抗網路─08_創作_AI_5.jpg)
> 
> <center><font color="#7f7f7f">圖 8-10(b) | 判別器、生成器的 parameters 第二次更新後的判別情況</font></center>

經過第二輪優化後，落在 3~7 之間的 data，discriminator 皆會給予 0.5 的分數，代表著 discriminator ==已無法分辨出 true or fake==，也就是這個被訓練後的 NN 可以以假亂真了。

# 8-3 條件式生成對抗網路
[[#8-2 生成對抗網路|上一小節]]介紹了基本的 GAN生成對抗網路，也就是將 latent space 的 data point *映射(project)* 到我們想要的資料空間，可視為 model 在學習 **點對點(point-to-point)** 的對應關係。
但這麼做較難控制生成的結果。

> [!quote] 說明
> 舉例來說，如果希望 generator 產生一張戴眼鏡、瀏海偏長的男性臉孔，我們會不知道在生成網路的 input 應該放什麼資訊。

所以這時應使用 條件式生成對抗網路(Conditional Generative Adversarial Network, conditional GAN)，只需要對 GAN 原有架構些微調整即可。
![8-3_條件式生成對抗網路─08_創作_AI|圖 8-11 | conditional GAN structure|500](https://raw.githubusercontent.com/kaisnowwolfhan/Obsidian-Images/refs/heads/master/8-3_條件式生成對抗網路─08_創作_AI.jpg)
<center><font color="#7f7f7f">圖 8-11 | conditional GAN structure</font></center>

> [!quote] 說明
> 假設 \[1, 0\] 代表戴著眼鏡，\[1, 1\] 代表戴著眼鏡且瀏海偏長。
> 將 \[1, 0\] 作為條件輸入 generator 產生結果後，再將產生的結果與 \[1, 0\] 一起輸入 discriminator，discriminator 必須要判斷 generator 的創作 是否戴著眼鏡 以及 是否像真實漫畫。

由於 GAN 的行為基於 discriminator 驅動，因此現在 discriminator 除了學會判別創作真偽以外，也必須學會判斷創作是否符合給定的條件。

# 8-4 循環式生成對抗網路
> [!quote] 說明
> 設想一個狀況，如果希望小明拿到一張真實的人臉照片時，能夠將其中的人臉畫成漫畫風格，該怎麼作呢?
> 我們的目標是希望小明根據給定的照片轉換成漫畫風格，但小華的任務是分辨圖片是否為漫畫風格，因此，如果小明創作出漫畫風格的風景畫 or 漫畫風格的人臉，雖然與給定的照片相差甚遠，小華還是有可能給出高分，所以我們需要另一個人來解決這個問題。

我們讓小美(generator 2)來執行這次的任務。由於油畫的特性能讓畫作非常逼真，因此小美(generator 2)的任務是將小明(generator 1)漫畫風格的創作用油彩繪製模仿成類似真實照片的風格，期望小美(generator 2)的作品能夠非常接近給定的照片。
如果小明(generator 1)不管真實照片，逕自將人臉照片畫成漫畫風格的風景畫，小美(generator 2)也只能畫出非常像真實相片的風景圖。加入額外目標後，小明(generator 1)就必須依照相片畫成漫畫風格。

這個要讓給定的照片與小美(generator 2)最後還原的結果相似的目標，稱為 **循環一致性(cycle consistency)**。

> [!quote] 說明
> 整個訓練過程改由小美(generator 2)發起，先將漫畫交給小美(generator 2)畫成擬真油畫風格，再請另外一個朋友小娟(discriminator 2)來判斷小美(generator 2)的作品是否像真實照片。
> 接著，小明(generator 1)將小美(generator 2)的擬真油畫作品轉換成漫畫風格。同樣為循環一致性，我們希望小明(generator 1)的創作結果與給小美(generator 2)的漫畫非常相似。

上述兩種方向不同的訓練方式並不衝突，他們四個人可以同時訓練。接下來，只要將他們四個人替換成類神經網路，整個模型就稱為 **循環式生成對抗網路(CycleGAN)**，架構如圖:

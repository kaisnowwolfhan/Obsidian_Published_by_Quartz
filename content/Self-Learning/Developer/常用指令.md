# cd
**進入絕對路徑**：`cd /var/www/html`
**返回上一層**：`cd ..`
**返回上兩層**：`cd ../..`
**回到「家目錄」**：`cd ~`
**回到剛才待過的目錄**：`cd -`
## 小技巧
1. 按 Tab 可自動補齊名稱
2. 名稱有空格可以用引號包起來，或用反斜線跳脫空格
	```powershell
	cd "My Documents"
	# 或者
	cd My\ Documents
	```

## 相關
`pwd`：顯示目前所在的資料夾完整路徑
`ls`： 列出目前資料夾底下有哪些檔案與子資料夾

# rm
- `-r`  (Recursive)：遞迴刪除，用於刪除資料夾及其包含的所有核心內容。
- `-f`  (Force)：強制刪除，不會跳出詢問視窗，也不會因為檔案不存在而報錯。
(可組合成 `-rf` 來強制刪除資料夾及其內容)

# vim
## 進入與離開
- `vim 檔名`：開啟或建立檔案
- `i`：在游標目前位置進入編輯模式
- `Esc`：從編輯模式返回一般指令模式
- `:w`：儲存檔案
- `:q`：離開
- `:wq` 或 `:x`：儲存後離開
- `:q!`：不儲存強制離開 

## 移動游標與尋找
- `h, j, k, l`：左、下、上、右移動游標
- `gg`：移動到檔案最上方第一行
- `G`：移動到檔案最下方最後一行
- `/關鍵字`：向下搜尋指定的文字內容

## 編輯、複製與刪除
- `yy`：複製游標所在的整行
- `p`：在游標下一行貼上複製的內容
- `dd`：刪除游標所在的整行
- `u`：復原（上一步）
- `Ctrl + r`：重做（下一步）

# 端口(port)佔用
## 查找端口佔用應用
```powershell
Get-NetTCPConnection -LocalPort 9000 | Format-List -Property PID, State
```

## 終止該佔用程序
```powershell
Stop-Process -Id <PID> -Force
```
